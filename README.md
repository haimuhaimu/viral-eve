# 爆款前夜 · Viral Eve

> **你能让一个没人看的主播出名，又不把他变成一个小丑吗？**

一款关于**内容创作、流量与代价**的 7 天叙事策略模拟游戏。你不是在做简单的剧情选择题，而是主播背后的操盘手：组装每天的内容策略，追逐爆款，也承担每次增长带来的代价。

## 30 秒了解游戏

- **组装，而非猜选项**：每天从选题、立场、形式、标题钩子与代价五类卡池中各选一张，拼出当天内容。
- **面对真实的利益冲突**：老粉、路人、硬核玩家、品牌方、黑粉、平台算法与同行，会对同一条内容给出不同反馈。
- **让数字留下后果**：播放、粉丝与收入上涨时，人设偏移、信任、专业度和压力也会改变，并共同决定结局。

**共有 8 种结局**：真正的高手 / 小而硬核 / 顶流小丑 / 恰饭机器 / 塌房 / 熄火 / 查无此人 / 迷失在流量里。

> 当前版本是可在线体验的原创纯前端 Demo；不需要注册，不包含后端服务，也不声称拥有未经验证的用户规模。

## 剧情

**冯野**，24 岁，打不上职业的前电竞青训，如今是个日均在线不到两百人的二线游戏主播。他想证明自己是真的懂游戏，可平台只奖励他破防炸毛的切片，而不是认真的深度分析。房租下周到期，账号连续 14 天低于流量扶持线。

你有 7 天。

## 核心玩法

每天一个循环：

1. **创作者后台** — 查看冯野当前的状态与心情
2. **平台简报** — 今日热点、被算法加权的方向、平台压力，以及接/拒品牌商单
3. **内容工坊（核心交互）** — 从五类卡池各选一张，组装出今天这一条内容：
   - 🎯 选题 · 🎭 立场 · 🎞️ 形式 · 🪝 标题钩子 · ⚖️ 牺牲/代价
4. **信息流模拟** — 发布，看播放量滚动、七大圈层评论逐条炸出
5. **数据结算** — 指标增减、各受众反应、冯野本人的一句真心话

**七个受众各有偏好**：老粉、路人、硬核玩家、品牌方、黑粉、平台算法、同行——同一条内容会得到七种截然不同的反应。

**每一次爆红都有代价**：流量会推高「人设偏移」、消耗「信任」和「专业度」。粉丝在涨，冯野却可能在走样。

## 结局系统

结局不是单一分数榜，而是由粉丝、专业度、信任、人设偏移、压力、收入与争议度等状态共同判定：

| 方向 | 可能结局 |
| --- | --- |
| 守住专业与信任 | 真正的高手 / 小而硬核 |
| 流量压过自我 | 顶流小丑 / 迷失在流量里 |
| 商业或争议失控 | 恰饭机器 / 塌房 |
| 没能撑到最后 | 熄火 / 查无此人 |

## 技术可信度

- **React 18 + TypeScript + Vite**
- **Tailwind CSS** + shadcn/ui 组件
- **framer-motion** 动效 · **lucide-react** 图标
- 纯前端、无后端，游戏数据保存在本地代码中
- 模拟逻辑以纯函数实现，游戏数据、状态计算与 UI 分离
- 生产构建同时执行 TypeScript project build 与 Vite 打包

## 项目结构

```text
src/
├── game/
│   ├── types.ts          # 全部类型定义（数据与逻辑的公共契约）
│   ├── engine.ts         # 模拟引擎（纯函数：反应计算 / 指标结算 / 评论 / 标签）
│   ├── state.ts          # 初始状态
│   └── data/             # 游戏数据（与 UI 分离）
│       ├── character.ts  # 主角冯野 & 初始指标
│       ├── cards.ts      # 五类内容卡池
│       ├── audiences.ts  # 七个受众群体及其偏好权重
│       ├── trends.ts     # 七天平台简报
│       ├── brandDeals.ts # 品牌合作邀约
│       ├── comments.ts   # 评论模板 & 冯野台词
│       └── endings.ts    # 8 种结局判定
├── screens/              # 7 个界面
│   ├── Landing.tsx / CreatorRoom.tsx / Briefing.tsx
│   ├── Crafting.tsx / FeedSim.tsx / Result.tsx / Ending.tsx
├── components/game/      # 游戏 UI 组件（Avatar / MetricsHUD / atoms）
├── lib/display.ts        # 展示层格式化与配置
└── App.tsx               # 天数循环控制器
```

## 本地运行

要求：Node.js 18+ 与 npm。

```bash
npm install
npm run dev
# 打开 http://localhost:5173
```

检查与生产构建：

```bash
npm run lint
npm run build
```
